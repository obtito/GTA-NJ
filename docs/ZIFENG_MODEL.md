# 紫峰大厦建模依据

本轮模型位于 `js/zifeng.js`，通过 `BUILDERS.supertall` 接入原城市与单体预览。
几何全部按米建立，再以 **X/Y/Z 同为 1/30** 映射到现有城市的单体尺度。
这保证建筑本身等比；城市底图仍使用项目原有的 1/100 水平比例。

[设计师说明](https://www.smithgill.com/work/zifeng_tower/)明确三角平面、两片互锁体量、竖横接缝、斜置错位玻璃和裙房花园。
该页的 458 m 属于与竣工资料不同的设计口径，本模型采用 CTBUH 的 450 m。

本地有效照片为 `ref/` 目录两张紫峰照(该目录仅本地保留、不随仓库分发,照片许可未逐张核实)。
前者有透视和底部裁切，不能直接把每一像素当等距标尺。部分其他本地参考照片有灰色损坏区，未用作全塔高度标定。

## 本轮修正

- 保留地理朝向与主楼、副楼、裙房的共同尺度。
- 固定三角形中核与错高的东西两翼替代整圈同步收分；西翼内侧先结束，外侧继续升高，东侧弧形翼与中核再分别结束。
- 约 160 m 宽肩、两翼之间的竖向深槽，以及从中段一直延续到柱冠的圆角脊线。
- 移除按错位窗格中心删面的占位开孔，凹槽边界以米制轮廓同时裁切玻璃、内衬和夜窗，避免错格黑斑。
- 下段按用户圈定区域重建连续倒 L 凹槽：宽正面横带与右端下接裙房的竖槽直接相通，采用统一后壁和外轮廓收边，转角不设封板。不再在下段两侧或中段弧翼上放置独立矩形洞口。
- 横带保留内退承重柱，竖槽保留后方层线、梁和底部斜撑；下段外壳在横带下方结束，上方横跨整个正面。
- 中上段取消西翼上孤立的矩形小窗，改为两翼之间从宽肩连续延伸到顶部交接处的错位深槽。西翼在248 m处收边，东翼在266 m处向西展开；转折处只封各自体块的屋面/悬挑底面。保留上端斜撑，补全内退玻璃、纵向框架与后部层梁。
- 斜置玻璃、金属竖梃、横向分缝和内退幕墙表现立面层次；固定随机种子保持日夜窗光可复核。
- 幕墙使用银青灰渐变、较深的青灰内层和暖银色金属短折边；两层同组的玻璃共用斜面相位，强化锯齿龙鳞反光，横框收细。
- 边角的裁切鳞片保持完整单元的斜率，夜窗沿玻璃斜面外移，避免角部异常闪光和窗光穿入玻璃。
- 柱状设备冠、细钢桅杆和航空灯沿主楼面积形心对齐，消除原有偏轴双尖。
- 航空灯缩回合理尺度；窗光只在夜间显示，静态细部在构建时合批。
- 单体预览支持日夜、四向观察、自由旋转缩放与自动完整取景。

这是依据公开数据和照片的等比外观重建，**尚不能认证施工图级 1:1 复刻**。
准确校准各退台、冠壳和幕墙需相应 CAD/BIM、标注立面图或经过尺度校准的多视角测量。

## 验证

`npm run check` · `npm run zifeng:check` · `npm run smoke`

几何回归检查总高、等比基底、顶点有效性、桅杆轴线、确定性及合批后的日夜控制；射线检查上下两处凹槽的实际进深、相邻外墙完整性，以及下段倒 L 转角、中上段178/248/266 m交界未被屋面、悬挑底面或侧墙封断。
